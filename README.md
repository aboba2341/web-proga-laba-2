# Летопись замыслов

ToDo-лист для писателей в эстетике дарк-фэнтези. Задачи оформлены как записи в рабочей хронике автора: главы, сцены и сроки, которые ты сам себе назначил.

**Деплой:** https://aboba2341.github.io/web-proga-laba-2/

Лабораторная работа №2 по веб-программированию ([задание](https://github.com/Dasha2101/WEB2025Q26LB2)).

## Возможности

- Добавление задачи с названием и сроком
- Удаление задачи (с анимацией «сгорания»)
- Редактирование названия и срока прямо в карточке (Enter сохраняет, Esc отменяет)
- Отметка о выполнении: название зачёркивается, запись выцветает
- Подсветка просроченных задач
- Сортировка по сроку (ближние / дальние) с сохранением собственного порядка
- Фильтр по статусу: все, в работе, завершённые
- Поиск по названию без учёта регистра и разницы «е»/«ё», с подсветкой совпадений
- Сохранение задач в `localStorage` и восстановление при загрузке
- Изменение порядка перетаскиванием: мышью (HTML Drag and Drop API), пальцем на сенсорных экранах (Pointer Events) и стрелками ↑ ↓ с клавиатуры
- Адаптивная вёрстка для ноутбука, планшета и телефона

## Технические решения

- **Только чистый JavaScript и DOM API**, без фреймворков и библиотек.
- **`index.html` содержит только каркас и подключение скрипта.** Вся страница, включая подключение CSS и шрифтов, создаётся в `js/main.js` через `createElement`, `className`, `textContent`, `setAttribute` и `append`.
- **Семантическая разметка:** `header`, `main`, `section`, `footer`, список задач на `ul`/`li`, даты в `<time datetime>`, подписи `<label>` у всех полей.
- **Данные отдельно от отображения.** Единственный источник правды — массив задач. Каждое действие меняет массив и вызывает `render()`, который перерисовывает список и сохраняет данные в `localStorage`. Сортировка, фильтр и поиск работают с копией массива и не портят пользовательский порядок.
- **Делегирование событий:** все действия с карточками обрабатываются слушателями на самом списке, поэтому работают и для карточек, созданных позже.
- **Безопасный вывод:** пользовательский текст вставляется только через `textContent`, `innerHTML` в проекте не используется.
- **Адаптивность** на CSS Grid и Flexbox, контрольные точки 720px и 480px.

## Структура

```
├── index.html      каркас и подключение скрипта
├── css/style.css   стили и медиазапросы
└── js/main.js      сборка страницы и вся логика
```

## Запуск локально

Сборка не нужна: достаточно открыть `index.html` в браузере.
